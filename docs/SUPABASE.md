# Подключение Supabase

Сейчас приложение работает в **демо-режиме**: данные лежат в localStorage браузера. Облачная синхронизация в коде ещё не подключена.

1. Создайте проект на supabase.com.
2. Выполните `supabase/schema.sql` в SQL Editor (таблицы и RLS-политики: каждый пользователь видит только свои строки).
3. В Authentication включите Email.
4. Создайте `.env.local`: `VITE_SUPABASE_URL=...` и `VITE_SUPABASE_ANON_KEY=...` (только anon-ключ; service_role на клиент не кладите).
5. Дальше нужен слой синхронизации (вход + запись/чтение таблиц вместо localStorage) — это следующий этап.
